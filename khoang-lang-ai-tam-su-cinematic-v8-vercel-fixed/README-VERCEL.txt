KHOẢNG LẶNG — VERCEL STATIC

Bản này không dùng build command, Node.js, framework hay server.
Đây là static site thuần HTML/CSS/JS và có thể deploy trực tiếp lên Vercel.

Cách deploy:
1. Upload/push toàn bộ NỘI DUNG của thư mục này lên GitHub, hoặc import repository vào Vercel.
2. Root Directory: thư mục chứa index.html.
3. Framework Preset: Other.
4. Build Command: để trống.
5. Output Directory: để trống.
6. Install Command: để trống.
7. Deploy.

Nếu dùng GitHub: index.html phải nằm ở root của repository (không nằm trong một thư mục con).
